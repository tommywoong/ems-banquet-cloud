📋 Hướng Dẫn Triển Khai Nhanh Pure Google Sheets (Free 1C & Paid 2A):

  2. Bước 2: Kéo thả file Excel lên Google Drive → Mở bằng Google Trang tính → Chọn Tệp → Lưu dưới dạng Google Trang tính.
  3. Bước 3 (Phương án Free 1C): Trong Google Sheet, vào Tiện ích mở rộng (Extensions) → Apps Script, dán nội dung file Google_Apps_Script_Backend.gs vào và bấm Triển khai (Deploy) → Ứng dụng web (Web App) (Quyền truy cập: Bất kỳ ai / Anyone). Copy URL Web App và Spreadsheet ID dán vào bên dưới.
